# Tachyon v0.0.17

- Add Themes and Canvas with five starter themes, six editable color roles, and the supplied color picker.
- Apply themes across the launcher and shared controls. Save, duplicate, export, and delete custom themes, with isolated drafts and text contrast feedback.
- Add spring interactions for swatches and pickers, shared preview expansion, keyboard focus handling, and reduced-motion support. The preview is a palette study ready for a future shader renderer.
- Consolidate Appearance into Themes. Move reduced motion, interface density, and the default sidebar state there, apply them launcher-wide, and migrate existing preferences.
- Pin Themes directly above Settings and add it to Spotlight quick navigation.

The theme system and appearance preferences persist on this device. Other Settings controls retain their existing preview/mock boundaries. The shader renderer is not included in this release.
