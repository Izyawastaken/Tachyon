# Tachyon v0.0.15

This release brings Library, Screenshots, Settings, Login and Home into the launcher shell. It integrates the completed work into `exp-dev` and keeps the existing Explore and Skins features.

## Page status

| Page | Status | Working behavior and remaining boundaries |
| --- | --- | --- |
| Home | Real backend | Rust retrieves public Moddex discovery feeds for Trending and Hidden Gems, with Engram caching, refresh, errors and retries. Trending measures distinct raters in the latest 50-rating sample for recently created mods; it is not a download-growth ranking. Browser tests use synthetic fixtures. |
| Library | Mostly mock / UI preview | Sample pods, playtime, content, files, worlds, logs, creation, settings and simulated installs live in memory and reset on reload. The share-code lookup is real: Rust validates a Neutrino-Obscura code and resolves public GitHub repository metadata. Continuing creates an empty preview pod; it does not import repository files, install dependencies or launch Minecraft. Share-code generation is not connected. |
| Explore | Real backend | Rust queries Modrinth for projects, filters, details and releases; caches descriptions and media; and downloads selected files with integrity checks and cancellation. A downloaded file is not automatically installed into a pod. |
| Skins | Real local library and remote imports | Native PNG import/export, persistent local selection, favorites, rename, removal/undo, player/official-texture lookup and the 3D preview work. Selection is saved in Tachyon; Minecraft account skin sync is not connected. |
| Screenshots | Real local backend | Rust discovers the default Minecraft screenshots folder, links additional instance folders through a native picker, persists linked sources and scans actual PNG files. The page supports search, filters, sorting and a gallery viewer. This browses existing captures; it does not capture the game or upload images. Browser tests use fixtures. |
| Login / Account | Mock / UI preview | A cancellable demo sign-in returns `TachyonPlayer`, supports retry and sign-out, and resets on reload. No Microsoft browser authentication, credentials, tokens, ownership verification or real account session is connected. |
| Settings | Mock / UI preview with browser persistence | Categories, search, scope overrides, validation, confirmation dialogs and settings import/export work against preview preferences saved in browser storage. Detection, accounts, diagnostics and maintenance results are synthetic. Preferences do not configure the native launcher; appearance previews stay inside Settings. |
| Sidebar instances / Add instance | Placeholder | The sidebar lists sample instances and can add an in-memory entry. These entries do not open a completed instance page or create a real game installation. Use Library for the pod workspace preview. |

The launcher shell and navigation are implemented. The existing updater uses the signed Tauri update path. This release does not add a real Minecraft instance installation or launch pipeline.

## Verification

- Production frontend build: passed, with the existing large 3D-viewer chunk advisory.
- Rust library tests: 35 passed; 6 opt-in live-service/fixture tests were skipped.
- Browser suites: 29 passed across Home (4), Library (6), Screenshots (5), Login (6) and Settings (8).
- Corrected the Login test server's working directory so its suite starts independently.

Browser fixtures verify UI behavior independently of live services and native dialogs. Optional live network tests were not run for this release. The Screenshots development harness emitted ResizeObserver notification warnings during resizing; its five interaction checks passed.

## Branch archive

After merging, merged feature branch tips are preserved as annotated tags under `archive/v0.0.15/`, then their local and remote branches are removed. `main` and `exp-dev` remain active. The temporary release integration branch is archived in the same way. A branch can be restored from its archive tag with `git switch -c <branch> archive/v0.0.15/<branch>`.
