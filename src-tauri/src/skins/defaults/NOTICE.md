The PNGs in this directory are Minecraft default character textures by Mojang Studios / Microsoft, extracted from the official Minecraft Java Edition 1.21.1 client for the requested skin picker. They remain the property of their respective owners and are not covered by any license for Tachyon's application code.

`sources.json` records the official client download URL, verified client SHA-1, original archive paths, and SHA-256 of each extracted PNG. Both classic (wide) and slim variants are bundled for Steve, Alex, Ari, Efe, Kai, Makena, Noor, Sunny and Zuri.

Official character announcement: https://www.minecraft.net/en-us/article/introducing-new-default-skins
